# 🏛️ Heritage Hub

Heritage Hub is a Django-based skill-sharing platform designed to connect people who have valuable traditional skills with learners who want to discover and learn those skills.

The platform aims to help preserve traditional knowledge by providing a digital space where skills can be shared, discovered, and learned.

## 📌 Project Overview

Many traditional and valuable skills are gradually disappearing because experienced skill providers do not always have a platform to share their knowledge with the next generation.

Heritage Hub provides a platform where users can:

- Share their skills
- Discover traditional skills
- Connect with skill providers
- Learn valuable practical knowledge
- Preserve cultural and traditional knowledge

## ✨ Features

- 👤 User registration and authentication
- 🧑‍🏫 Skill provider profiles
- 🎓 Skill learner profiles
- 🔍 Search and discover skills
- 📚 Skill details
- ➕ Create and manage skills
- 📅 Booking/session functionality
- 💬 User interaction
- 🏛️ Traditional skill preservation
- 📱 Web-based user interface
